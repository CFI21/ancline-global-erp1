# Phase 13 UAT

1. Reports dashboard returns booking status, branch and finance summaries.
2. Report snapshot can be generated and appears in database.
3. Master-data change request is created as PENDING.
4. Same requester cannot approve own master-data change.
5. Global Admin can approve another requester's change.
6. User scope assignments require Global Admin.
7. Audit Center returns recent audit, master-data and scope events.
8. Release Control reports database/API state plus pending approvals, tasks and exceptions.
